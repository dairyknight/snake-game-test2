### T2: Board.ts — full implementation + tests

**Files:**
- `src/game/Board.ts` (complete implementation)
- `tests/Board.test.ts` (new)

**Spec:**
- Class `Board`:
  - constructor(width = 20, height = 20): stores readonly width, height
  - `checkCollision(pos: Vector2, snake: Snake): boolean`:
    - Wall: `pos.x < 0 || pos.x >= this.width || pos.y < 0 || pos.y >= this.height`
    - Self: check `pos.equals(seg)` for each seg in `snake.segments` EXCEPT `snake.segments[0]`
      (segments[0] is the current head — skip it to avoid false self-collision)
    - Return true if either check fires; false otherwise

**Tests (see phase-4-test-plan.md Board.test.ts section):**
All wall edges, boundary non-collisions, self-collision (body + tail), head skipped, custom dimensions.

**CRITICAL:** Document in a comment WHY segments[0] is skipped:
```
// segments[0] is the current head (already moved into pos by Snake.move()).
// Checking pos against itself would always return true. We check body[1..] only.
```

    - Calls respawn(occupied) to set initial position

Note on Food construction: `_food` must be initialized with the same snake's segments,
not a temporary new Snake(). Initialize both in a helper or use a two-step init:

```typescript
private readonly _board: Board;
private _snake: Snake;
private _food: Food;
private _pendingDirection: Direction | null = null;

constructor() {
  this._board = new Board();
  this._snake = new Snake();
  this._food = new Food(this._board.width, this._board.height, Array.from(this._snake.segments));
}
```

New public methods:
```typescript
queueDirection(direction: Direction): void {
  this._pendingDirection = direction;
}

getSnake(): Snake {
  return this._snake;
}

getFood(): Food {
  return this._food;
}
```

Populate update():
```typescript
update(_deltaTime?: number): void {
  if (this._state !== GameState.PLAYING) return;

  const dir = this._pendingDirection ?? this._snake.currentDirection;
  this._pendingDirection = null;

  this._snake.move(dir);

  if (this._board.checkCollision(this._snake.head, this._snake)) {
    this.endGame();
    return;
  }

  if (this._food.position.equals(this._snake.head)) {
    this._snake.grow();
    this._food.respawn(Array.from(this._snake.segments));
    this.events.emit('foodEaten', undefined);
  }
}
```

Populate restartGame() (replace TODO comment):
```typescript
restartGame(): void {
  if (this._state !== GameState.GAME_OVER) return;
  this._snake = new Snake();
  this._food = new Food(this._board.width, this._board.height, Array.from(this._snake.segments));
  this._pendingDirection = null;
  this._transition(GameState.IDLE);
}
```
