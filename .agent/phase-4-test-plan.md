## Snake.test.ts

### Initial state
- Snake constructs with exactly 3 segments
- `head` returns `(10, 9)` (first segment)
- `segments` = `[(10,9), (9,9), (8,9)]` (head to tail)
- `currentDirection` = `RIGHT` (`Vector2(1, 0)`)

### move() — direction changes
- `move(RIGHT)`: head becomes `(11,9)`, segments = `[(11,9),(10,9),(9,9)]`, length = 3
- `move(UP)`: from initial, head becomes `(10,8)`, length stays 3
- `move(DOWN)`: from initial, head becomes `(10,10)`, length stays 3
- `move(LEFT)`: from a snake moving UP, head moves left — new head = `(9,8)`
- After each move, `currentDirection` is updated

### move() — 180° reversal blocked (4 cases)
- Moving RIGHT → `move(LEFT)` → continues RIGHT, head = `(11,9)` not `(9,9)`
- Moving UP → `move(DOWN)` → continues UP
- Moving LEFT → `move(RIGHT)` → continues LEFT (set up by moving UP then LEFT first)
- Moving DOWN → `move(UP)` → continues DOWN
- Same direction repeated: `move(RIGHT)` twice → allowed, snake moves forward

### grow() + move()
- After `grow()` then `move(RIGHT)`: length = 4, tail `(8,9)` retained
- After `grow()` then `move(RIGHT)`: `currentDirection` still updated correctly
- `grow()` called twice before `move()`: length increases by 1 only (boolean flag, not counter)
- After grow+move, subsequent `move()` without grow removes tail normally (back to length 4)

### segments readonly
- `snake.segments` returns the same values as used for head checks
- Verifies snapshot: mutation of returned array doesn't affect snake internals

## Board.test.ts

### Wall collisions — all four edges
- `checkCollision(Vector2(-1, 10), snake)` → `true`
- `checkCollision(Vector2(20, 10), snake)` → `true`
- `checkCollision(Vector2(10, -1), snake)` → `true`
- `checkCollision(Vector2(10, 20), snake)` → `true`

### Boundary: exactly on valid cells (not collisions)
- `checkCollision(Vector2(0, 0), snake)` → `false` (snake not there)
- `checkCollision(Vector2(19, 19), snake)` → `false`
- `checkCollision(Vector2(0, 19), snake)` → `false`
- `checkCollision(Vector2(19, 0), snake)` → `false`

### Self-collision
- Setup: snake with segments at known positions
- `checkCollision(segments[1], snake)` → `true` (first body cell = old head)
- `checkCollision(segments[last], snake)` → `true` (tail)
- `checkCollision(segments[0], snake)` → `false` (current head is SKIPPED — not a collision)

### No collision
- Valid position not on snake and not on wall → `false`

### Custom board dimensions
- `new Board(10, 10)`: `checkCollision(Vector2(10, 5), snake)` → `true` (out of 10-wide board)
- `new Board(10, 10)`: `checkCollision(Vector2(9, 9), snake)` → `false` (in bounds, not on snake)

## Food.test.ts

### Deterministic spawn with injected RNG
- `new Food(20, 20, [], () => 0)` → picks cell index 0 of all-available → `(0, 0)`
- `new Food(20, 20, [], () => 0.999)` → picks last available cell → `(19, 19)`
- Verify `food.position` equals the expected deterministic cell

### respawn() — basic
- `respawn([])` returns `true`, position is some valid board cell
- `respawn()` with occupied=[food.position]: new position is not the old position
- After `respawn()`, `food.position` is not in occupied list

### respawn() — avoidance property test
- Run 50 iterations: generate random snake segments (5-20 length), call respawn(), assert `food.position` is not in occupied
- Deterministic via seeded RNG sequence

### respawn() — board full
- occupied = all 400 cells of a 20×20 board
- `respawn(allCells)` → returns `false`
- `food.position` unchanged after returning false

### respawn() — near-full board
- occupied = 399 cells (all except `(15,15)`)
- `respawn(occupied)` → returns `true`, `food.position.equals(new Vector2(15, 15))`

### Food constructor with occupied cells
- `new Food(20, 20, [new Vector2(10,9), new Vector2(9,9), new Vector2(8,9)])` — initial position not on those cells
- Verify with deterministic RNG injected

## GameManager.test.ts — additions

### update() state gating
- `update()` when state=IDLE → no state change, no events (guard works)
- `update()` when state=PAUSED → no state change (already tested; verify with entities present)

### update() — wall collision triggers GAME_OVER
- Set up snake near a wall
- Call `update()` enough times to walk snake into the wall
- Assert state = GAME_OVER
- Assert `gameOver` event fired with `{ score: 0 }`

### update() — food eaten
- Use injected RNG to place food at a known cell
- Move snake toward food cell (calls to `queueDirection` + `update()`)
- Assert `foodEaten` event fired (once)
- Assert snake length increased by 1
- Assert food position changed (respawned)

### update() — self-collision triggers GAME_OVER
- Construct a scenario where snake grows several times and then doubles back
- Assert GAME_OVER when head reaches its own body

### queueDirection()
- Queue RIGHT while moving RIGHT: next update() moves right (same dir, no block)
- Queue LEFT while moving RIGHT: next update() moves right (180° block, LEFT ignored)
- Queue UP while moving RIGHT: next update() moves up (valid perpendicular)
- After one update(), pending direction is cleared: subsequent update() uses currentDirection

### restartGame() — entity reset
- Start game, update several times, trigger GAME_OVER
- Call `restartGame()`
- Assert state = IDLE
- Assert `getSnake().segments.length === 3`
- Assert `getSnake().head.equals(new Vector2(10, 9))` (back to initial position)
- Assert `getFood().position` is a valid board cell
- Assert next `startGame()` + `update()` works without throwing

### getSnake() / getFood()
- `getSnake()` returns Snake instance (instanceof Snake)
- `getFood()` returns Food instance (instanceof Food)
- These are the same instances mutated by `update()`

## Critical Paths

1. Snake spawns at correct centre position → moves right on first tick → no immediate collision
2. Snake eats food → grows → new food spawns not on snake → no crash
3. Snake hits wall → GAME_OVER event fires → GameLoop stops
4. Snake self-collides → GAME_OVER event fires
5. restartGame() → entities reset → new game starts cleanly
