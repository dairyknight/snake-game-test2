## Key Interactions to Verify

### GameManager — Valid State Transitions
- `startGame()` when IDLE → state becomes PLAYING, stateChange event fired with { from: IDLE, to: PLAYING }
- `pauseGame()` when PLAYING → state becomes PAUSED, stateChange event fired
- `resumeGame()` when PAUSED → state becomes PLAYING, stateChange event fired
- `endGame()` when PLAYING → state becomes GAME_OVER, stateChange event fired
- `restartGame()` when GAME_OVER → state becomes IDLE, stateChange event fired

### GameManager — Invalid Transitions (silent no-op)
- `startGame()` when PLAYING → state unchanged, no event
- `pauseGame()` when IDLE → state unchanged, no event
- `pauseGame()` when PAUSED → state unchanged, no event
- `resumeGame()` when IDLE → state unchanged, no event
- `resumeGame()` when PLAYING → state unchanged, no event
- `endGame()` when IDLE → state unchanged, no event
- `endGame()` when PAUSED → state unchanged, no event
- `restartGame()` when IDLE → state unchanged, no event
- `restartGame()` when PLAYING → state unchanged, no event

### GameManager — togglePause
- `togglePause()` when PLAYING → PAUSED
- `togglePause()` when PAUSED → PLAYING
- `togglePause()` when IDLE → no-op, no event

### GameManager — Initial State
- `new GameManager()` → `getState()` returns IDLE
- `new GameManager()` → `getScore()` returns 0

### EventEmitter
- `on()` + `emit()` → handler receives correct typed data
- Multiple `on()` handlers → all called on emit
- `off()` → handler not called after removal
- `off()` for unregistered handler → no throw
- `emit()` with no registered handlers → no throw

### Vector2
- `new Vector2(3, 4)` → `.x === 3`, `.y === 4`
- `equals()` same position → true
- `equals()` different x → false
- `equals()` different y → false
- `equals()` different x and y → false

## Edge Cases
- `togglePause()` when IDLE (not PLAYING or PAUSED) — must silently do nothing
- `togglePause()` when GAME_OVER — must silently do nothing
- `restartGame()` when already IDLE — silently no-op
- `endGame()` when PAUSED — silently no-op (collision cannot trigger while paused; GameManager must guard this)
- Full round-trip chained transitions: IDLE→PLAYING→PAUSED→PLAYING→GAME_OVER→IDLE — all states correct at each step

## Critical Paths
- Complete game lifecycle: startGame → endGame → restartGame → startGame (proves round-trip works end-to-end)
- Pause/resume cycle mid-game: startGame → pauseGame → resumeGame → state returns to PLAYING
- Event subscriber receives stateChange payload: verify { from, to } fields are both present and correct
